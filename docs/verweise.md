# Zweites Beispieldokument

Diese Datei ist absichtlich klein. Sie dient dazu, den **Wechsel zwischen Dokumenten**
im Viewer zu testen: Im [ersten Beispieldokument](beispiel.md) gibt es einen Link
hierher.

## Was hier passiert

Wenn Sie im Viewer auf einen Link zu einer anderen `.md`-Datei klicken, öffnet sie sich
in einem **neuen Tab** – der ursprüngliche Tab bleibt erhalten.

## Bilder aus dem Nachbarordner

Relative Pfade werden immer vom Ordner der geöffneten Datei aus aufgelöst, deshalb
funktioniert auch dieses Bild:

![Logo](bild.png "Titel erscheint als Tooltip")

## Nützliche Tastenkürzel

| Kurztaste | Wirkung |
| --- | --- |
| `Strg+Umschalt+O` | Datei in neuem Tab öffnen |
| `Strg+R` | Dokument neu laden |
| `Strg+W` | Tab schließen |
| `Umschalt+F3` | vorheriger Suchtreffer |
| `Strg+0` | Schriftgröße auf 100 % |

## Noch ein wenig Text zum Scrollen

> [!TIP]
> Wenn eine geöffnete Datei auf der Festplatte geändert wird, lädt MD Viewer die
> Anzeige automatisch neu – praktisch beim Schreiben in einem anderen Programm.

Zeile eins
Zeile zwei
Zeile drei

Mit der Einstellung *Darstellung → Einzelne Zeilenumbrüche umbrechen* werden daraus
drei sichtbare Zeilen.
